# 급여명세서 스튜디오 · 5인 미만 주휴수당 1분 생성기

소상공인·자영업자가 매달 알바·직원 급여날 가장 골치 아픈 **법정 임금명세서 작성 + 주휴수당·4대보험 계산**을 1분 안에 끝내는 무서버 정적 웹앱입니다.
`index.html` 하나로 동작하며, 계산은 100% 브라우저에서 이뤄집니다. **서버 전송 0건, CDN·분석 도구 0개.**

- A4 1페이지 급여명세서 인쇄 / PDF 저장
- 카톡·문자 전송용 텍스트 1클릭 복사
- 직원별 프로필을 `localStorage`에 저장 → 다음 달엔 시간만 바꿔 10초 만에 재발급
- JSON 내보내기/불러오기로 기기 변경·백업

## 바로 쓰기

1. `index.html`을 브라우저에서 연다(로컬 파일 또는 정적 호스팅).
2. 사업장·직원 정보를 입력한다. 처음에는 **예시 값**이 채워져 있으니 우리 정보로 바꾼다.
3. 근무시간·시급(또는 월급)을 넣으면 주휴수당·4대보험·소득세·실수령액이 즉시 계산된다.
4. `인쇄 · PDF` → 인쇄 창에서 용지 **A4**, 배율 **100%**, 대상 **PDF로 저장**.

> 입력값은 그 브라우저의 `localStorage`에만 남습니다. 어떤 값도 외부로 전송되지 않습니다.

## 계산 기준 (2026년)

| 항목 | 적용값 | 근거 |
| --- | --- | --- |
| 최저임금 | 시급 **10,320원** / 월 209시간 **2,156,880원** | 고용노동부 고시 제2025-47호 (2026.1.1~12.31) |
| 국민연금 (근로자) | **4.75%** | 국민연금법 부칙(법률 제20903호) 제4조 — 2026년 9.5%의 절반 |
| 건강보험 (근로자) | **3.595%** | 국민건강보험법 시행령 제44조 — 2026년 7.19%의 절반 |
| 장기요양보험 | 건강보험료의 **13.14%** (0.9448% ÷ 7.19%) | 노인장기요양보험법 제9조·시행령 제4조 |
| 고용보험 (근로자) | **0.9%** | 보험료징수법 시행령 제12조 (실업급여 1.8%의 절반) |
| 근로소득세 | 자동 추정 또는 간이세액표 금액 직접 입력 | 국세청 근로소득 간이세액표 |
| 프리랜서 | 사업소득세 **3%** + 지방소득세 **0.3%** | 소득세법 제129조·제134조 |

- **월 소정근로 60시간 미만**이면 국민연금·건강보험(장기요양 포함) 사업장가입 대상이 아니므로 자동으로 공제하지 않고, 고용보험만 적용합니다. 4대보험은 `자동 / 가입 / 미가입`으로 직접 바꿀 수 있습니다(다른 사업장 가입, 65세 이상 신규 고용 등 예외 대응).
- 국민연금 기준소득월액은 **천원 미만 절사** 후 상·하한을 적용합니다. 2026년 7월~2027년 6월 하한 41만원·상한 659만원, 2026년 1~6월은 40만원·637만원.
- 건강보험료는 원 단위 절사 후 근로자 부담 상·하한(10,080원~4,591,740원)을 적용하고, 장기요양보험료는 건강보험료를 기준으로 10원 미만 절사합니다.
- 지방소득세는 소득세의 10%, 10원 미만 절사.
- 사업주 부담 참고액은 국민연금·건강보험·장기요양은 근로자와 같은 금액, 고용보험은 0.9% + 고용안정·직업능력개발 0.25%(150인 미만)로 계산합니다. **산재보험은 업종별 요율이라 제외**했습니다.

### 주휴수당

- 4주 평균 1주 소정근로시간이 **15시간 이상**이고 소정근로일을 **개근**하면 발생합니다.
- 1일분 = 시급 × 1일 소정근로시간(주 소정근로 ÷ 근로일수, 최대 8시간).
- 이번 달 지급분 = 1일분 × 해당 월 주휴일(선택한 요일) 횟수. 예: 주 20시간·주 4일(1일 5시간), 주휴일 일요일, 2026년 11월 → 5시간 × 10,320원 × 5회 = **258,000원**.
- **5인 미만 사업장에도 근로기준법 제55조 제1항의 주휴일(주휴수당)은 적용됩니다.** 5인 미만에서 적용되지 않는 것은 제55조 제2항(공휴일)과 제56조(연장·야간·휴일 가산수당)입니다. 이 앱은 5인 미만 선택 시 가산수당을 100%로 계산하고 그 사실을 화면에 표시합니다.
- 월급제는 월급에 주휴수당이 포함된 경우 기본급과 주휴수당으로 나눠 표시하며, ‘주휴 별도 지급’으로 바꾸면 월급 위에 주휴수당을 더합니다.

### 임금명세서 법정 기재사항

근로기준법 제48조 제2항, 같은 법 시행령 제27조의2에 따라 다음을 담습니다.

1. 근로자 성명·생년월일·사원번호 등 식별정보
2. 임금 지급일
3. 임금 총액
4. 임금 구성항목별 금액과 계산방법(근로시간×시급, 연장·야간·휴일 시간 포함)
5. 공제항목별 금액과 계산방법
6. 총 근로시간 수

교부 의무는 **상시 5인 미만 사업장에도 적용**되며, 위반 시 500만원 이하 과태료 대상입니다(제116조 제2항, 시행령 별표 7 — 1차 30만·2차 50만·3차 이상 100만원).

### 소득세 자동 추정의 한계

자동 모드는 연간 환산 근로소득공제·기본공제·연금/건강보험료 공제·근로소득세액공제로 월 원천징수액을 **추정**합니다. 실제 회사는 국세청 **근로소득 간이세액표**를 적용하므로, 정확한 금액이 필요하면 `소득세 → 간이세액표 직접 입력`에 해당 금액을 넣으세요. 명세서에도 추정치 고지가 인쇄됩니다.

## 검증

```bash
node test.js      # 계산 코어 160개 단언
python3 uitest.py # 실제 Chrome 210개 항목 (데스크톱 1440x900 · 모바일 390x844)
```

`test.js`는 `index.html`의 `/* ==CORE-START== */ ~ /* ==CORE-END== */` 블록을 그대로 읽어 실행하므로, 브라우저에서 도는 코드와 같은 코드를 검증합니다.

`uitest.py`는 로컬 Chrome for Testing(`/workspace/scratch/calc/bin`)과 Playwright가 필요합니다. 폴더를 HTTP로 서빙하고, Chrome 기동이 일시적으로 실패하면 드라이버를 재시작하며 최대 12회 재시도합니다.

검증 항목:

- 주 15시간 경계(14.9/15), 개근·결근, 주휴일 요일별 횟수(2026년 11월 일 5회·수 4회)
- 5인 미만/이상 연장·야간·휴일 가산(150%/200%), 휴일 8시간 초과 분리
- 2026년 4대보험 요율·상하한·절사, 상반기/하반기 국민연금 상한
- 월 60시간 미만 4대보험 자동 미가입 판정과 가입/미가입 수동 전환
- 식대·교통비 월 20만원 비과세와 초과분 과세
- 간이세액 직접 입력, 프리랜서 3.3%, 월급제 주휴 포함/별도
- 최저임금 미달 경고, 실수령액 0원 클램프
- localStorage 저장·불러오기·2단계 삭제, JSON 내보내기/불러오기(깨진 파일 포함)
- 클립보드 복사
- Chrome 인쇄 파이프라인으로 **실제 A4 PDF 1쪽**(595×842pt) 확인, UI 문구 미포함 확인
- 모바일 가로 스크롤 없음, 하단 요약 바, 확대 모드, 터치 타깃 36px 이상
- 외부 요청 0건, 콘솔/페이지 에러 0건

## 계산 엔진 — decimal.js (MIT)

- 4대보험·소득세·수당을 전부 `decimal.js`(MIT, v10.6.0) 고정밀 연산으로 처리합니다. `assets/vendor/decimal.js`는 저장소 안 파일이라 실행 중 외부 요청이 없습니다.
- 10원 단위 절사(`floor10`), 원 단위 절사, 천 원 단위 내림(`floorTo`)을 명시적 반올림 모드로 고정했습니다. 기존 코드의 `+ 1e-7` 부동소수 보정 트릭은 제거했습니다.
- 실측 예: 과세 3,000,000원의 고용보험 0.9%는 부동소수로는 26,999원, 정밀 연산으로는 27,000원입니다. 주 9시간 계약의 월 소정근로시간은 39.1시간이 아니라 39.11시간입니다.
- 검증: `node test.js` 179개 통과, `python3 uitest.py` 실제 Chrome 217개 통과.
